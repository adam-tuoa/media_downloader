## Installing

Download the file for your computer, then:

**Windows** — run `UsefulMedia-windows-x64-setup.exe`. Windows may show a blue
"Windows protected your PC" box the first time: click **More info**, then **Run anyway**. The
installer puts *UsefulMedia* in your Start menu (and on the desktop if you tick the box) and
can open it straight away. No admin password needed.

**macOS** — unzip `UsefulMedia-macos-x64.zip`, then open **Terminal**, type `xattr -cr ` (with
a space after it), drag the *UsefulMedia* icon from Finder onto the Terminal window and press
Enter. No output means it worked; now double-click the app. This is needed once because the app
isn't notarized by Apple — without it macOS says it "could not verify" the app. The first launch
can take 20–30 seconds while macOS checks the new files.

**Linux** — `tar xzf UsefulMedia-linux-x64.tar.gz`, then run `UsefulMedia/UsefulMedia`.

The app opens in your web browser. Downloads go to `Downloads/UsefulMedia` (change it in
Settings). Use the **Quit** button to stop it. If YouTube stops working one day, open Settings
and press **Update now** — the app also checks for downloader updates every time it starts.

**Had Media Downloader before?** This is the same app with a new name. Your settings, Library
and download folder carry over the first time UsefulMedia starts. On Windows the installer
replaces the old copy; on macOS you can delete the old *Media Downloader* app.
