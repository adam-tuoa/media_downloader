# Media Downloader — downloads

A small, friendly desktop app for saving videos and music from YouTube, Vimeo and Bandcamp for
personal use. Paste links (videos, playlists, albums), choose video quality or an audio format,
and the files land in a folder with cover art and tags. Built on [yt-dlp](https://github.com/yt-dlp/yt-dlp).

**Get it from the [latest release](../../releases/latest)** — there's a zip for Windows, one for
macOS and a tar.gz for Linux, with install notes on the release page.

This repository only hosts the downloads. Please respect the terms of the sites you download
from and the rights of the people who made the videos and music.
